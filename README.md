# LASHÉA & CO — Prototype de boutique

Prototype de présentation indépendant de Shopify, en français et adapté aux téléphones.

## Fonctionnalités
- Accueil, catalogue GlowUp / HydraBoost, offres, FAQ
- Formats 1, 5 et 10; prix et rabais **indicatifs à valider**
- Panier fonctionnel conservé dans le navigateur
- Simulation de caisse **sans paiement réel**

## Prévisualisation
Le projet est statique : ouvrir `index.html` localement ou publier via GitHub Pages.

Pour publier : **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

URL attendue après activation : https://gilli999.github.io/Lashea-co/

## Important
**Prototype seulement.** Pas de paiement, de commandes réelles, de stockage client ni de serveur. Ne pas saisir de données de paiement. Les illustrations de flacons sont provisoires; demander à la marque de valider photos, prix, textes, allégations, rabais et politiques avant lancement.

Pour une vraie boutique : backend sécurisé, Stripe Checkout + webhooks, taxes, livraison, inventaire, remboursements, courriels, sauvegardes, conformité et tests.

Projet distinct de MOTRIX.
